# 添加一篇笔记

1. 复制本目录中合适的模板到日常“发布文档”文件夹的相应子文件夹。
2. 填写真实内容，设置一个唯一、稳定的小写英文 `id`（可含数字与短横线）。
3. 完成检查后把 `draft: true` 改为 `draft: false`，交给现有自动发布流程处理。

## 首页字段

|字段|填写方法|
|---|---|
|stage|`foundation` 积累；`application` 应用；`progress` 进展。省略时进入积累。|
|short_title|节点旁的短标题；建议约 8–14 个字。省略时显示原标题，最多两行。|
|event_date|真实发生日期，格式 `YYYY-MM-DD`。知识文章可以留空；不会自动把修改时间当作经历日期。|
|kind|可写学习笔记、训练日志、比赛复盘、阶段进展。写 `模板` 或 `template` 时保留搜索入口，但不进入首页成长图。|
|domain|`tennis` 网球、`fitness` 健身、`plans` 训练计划；也接受中文领域名。|

放在名为“模板”或“模版”的子文件夹中的文章也会标记为模板。

## 怎样写连接

在正文中写 `[[已发布文章标题]]`，接着说明这篇文章对当前问题有什么帮助。也可用 `[[稳定id|显示文字]]`。

笔记关系不是按相同标签猜测出来的。尚未发布的引用会显示提示，文章本身仍可发布；同名歧义或丢失图片会阻止本次更新，保留上次成功版本。

日常流程仍是 Markdown 文件进入“发布文档”后同步网页。这里的模板和 `docs/` 提示词不会自动成为网页文章。
